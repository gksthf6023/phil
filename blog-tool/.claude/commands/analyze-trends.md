규칙 5: **사용자가 제공한 자료로만** 분석한다. 검색결과 자동 수집·크롤링 금지.

1. 사용자에게 키워드와 자료(상위 노출 글 본문, 스마트블록 캡처 이미지 등)를 요청하거나 $ARGUMENTS 를 읽는다. 이미지는 Read로 직접 본다.
2. 분석: 글자수·사진 수·소제목 패턴, 공통 정보 항목, 스마트블록 주제 분류, 제목 패턴, 공통 빠진 정보(기회).
3. `data/trends.md`에 날짜·키워드·제공 자료 수와 함께 누적 기록.
4. 다음 `/write`에 반영할 점 3가지 이내로 보고.
