규칙 5: **사용자가 제공한 글로만** 학습한다. 블로그 크롤링·자동 수집 금지. 네이버 블로그 URL은 WebFetch가 막혀 있을 수 있으니 재시도하지 말고 본문 붙여넣기를 요청한다.

1. $ARGUMENTS 의 글(또는 사용자가 붙여넣은 글)을 읽는다. 3편 미만이면 더 요청.
2. 분석: 평균 문장·문단 길이, 종결어미·접속어·입버릇, 이모지 빈도/위치, 도입·마무리 패턴, 피해야 할 표현.
3. `data/style-profile.md`를 갱신하고, `blogger-profile.md`와 충돌하는 부분은 사용자에게 어느 쪽을 따를지 묻는다.
4. 변경 요약을 보고.
