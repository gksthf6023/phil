# 네이버 블로그 초안 공장 (맛집 · 체험단/협찬 선발 목표)

사진 + 소재 정보 + 한줄 메모 → Claude Code가 사진을 직접 보고 글 작성 → **사용자 승인 후** 네이버 임시저장까지.
이 툴은 "초안 공장"이지 "무인 발행기"가 아니다. 발행은 항상 사람이 한다.

- 주제: 맛집 탐방 / 목표: 체험단·협찬 선발 / 활동 지역: 서울 용산
- 화자 톤: 솔직 담백한 리뷰어 (상세는 `data/blogger-profile.md` — 매 글 일관성의 단일 기준)

## 절대 규칙

1. **API 키 금지** — 모든 AI 작업은 Claude Code 세션 안에서. (`claude -p` 지원)
2. **발행 금지** — 임시저장까지만. `scripts/naver_draft.js`의 `installPublishGuard()`(에디터 로드 직후, 캡처 단계 클릭 리스너로 `button[data-testid="seOnePublishBtn"]` 클릭 차단)는 **어떤 경우에도 제거·약화하지 않는다.** 태그 입력을 위해 발행 패널을 열기 때문에 이 가드가 전제다.
3. **사실 지어내기 금지** — `data/profile.md`와 사진에서 확인된 것만. 확인 안 된 정보(가격·주차·웨이팅·영업시간 등)는 사용자에게 묻거나 뺀다.
3-1. **협찬 처리(표시광고법, 생략 불가)** — `/write`마다 협찬·체험단 여부를 확인(메모에 없으면 질문). 협찬이면 `data/sponsored-disclosure.md`의 대가 유형별 문구를 **글 상단 첫 블록**에 일반 text 블록으로 넣는다(업체 지정 문구가 있으면 그것 우선, quote 금지). 협찬 글에 "내돈내산"·"광고 아님" 금지. 내돈내산이 확인된 글만 그 표현을 쓸 수 있다.
4. 소재는 고객 사례가 아니어도 되나, 서사를 지어내지 말고 정직하게 자기 경험임을 밝힌다.
5. **학습 데이터 자동 수집 금지** — 사용자가 제공한 글로만 `trends.md`·`style-profile.md` 갱신.
6. 초안은 **사용자 승인 후에만** 임시저장.

## 글쓰기 공식

- **키워드**: 메인 1개(지역명 포함) — 제목 앞쪽·첫 문단·마지막 문단 배치, 본문 5~7회, 띄어쓰기까지 동일한 형태 1회 이상. 서브 2~3개는 소제목에 배치.
- **페르소나 필수**: 메인 키워드를 검색하는 1명을 구체 정의(지역·나이·직책·상황·감정)하고 그 사람에게 말 걸듯 쓴다. 초안 검수 보고에 페르소나 포함.
- **첫 문단 Yes-set**: 첫 2~3문장에서 페르소나의 상황·감정을 적중시켜 "맞아, 내 얘기다"를 연속 유도 + 결론 예고.
- **둘째 문단 권위 한 줄**: `data/authority-lines.md`에서 골라 변형해 툭 던지듯. 자랑·연락처 금지. 솔직함형이 가장 강력.
- **후킹 패턴** 매번 다르게: 손실 회피형 / 현장 몰입형 / 반전형 / 공감형. 직전 글과 같은 도입 금지(유사문서 회피).
- **홍보 냄새 제거**: 맛집 후기에서도 광고 어휘("강추", "꼭 가보세요 무조건", "최고의") 남발 금지. 업체명은 본문 3회 이내. 연락처는 글 전체 1회 이내.
- **가독성(모바일)**: 한 문장 = 한 줄, 한 블록 3~5줄. 리듬 파괴 장치(인용구/구분선/사진/소제목)를 300~400자마다. 핵심 문장은 quote 블록으로 글당 2~4개. 텍스트만 500자 연속 금지. 표는 "✔ 항목 — 내용" 체크리스트로.
- **기본 세팅**: 1,800~2,500자, 사진 10~15장(장당 텍스트 2~4문단. 사진이 적으면 억지로 늘리지 말고 있는 것만), 제목 25~32자, 제목 특수문자 금지, 외부링크 1개 이하, 사진 재사용 금지.
- **캡션**: 키워드 1~2회 자연 배치, 전체 사진의 절반 정도만.

### 맛집 필수 정보 체크리스트 (초안 검수 때 항목별 대조)

검색자가 원하는 실측 정보. **확인 안 된 건 묻거나 뺀다.**

- [ ] 교통 (지하철역·출구·도보 시간)
- [ ] 주차 가능 여부
- [ ] 웨이팅 (방문 요일·시간대 기준 실제 경험)
- [ ] 좌석 (테이블 구성·인원·분위기)
- [ ] 먹은 메뉴마다 **4종 세트**: 메뉴명 / 가격 / 맛 / 팁
- [ ] 단점 1개 이상 포함한 총평
- [ ] 영업시간·휴무일 (확인된 경우만)
- [ ] 협찬 여부 표기(규칙 3-1)

### 발행 체크리스트 (임시저장 후 안내)

태그 5~10개·지도·동영상·소제목 서식은 스크립트가 자동 처리. 실행 로그의 **"자동 처리 결과"** 블록을 읽고 ❗수동 필요 항목만 안내한다. 항상 안내할 수동 항목:
타겟 활동 시간대 발행 / 발행 후 24시간 수정 금지 / 주 2~3회 주기(하루 2건 이상 금지) / 협찬 표기 육안 확인 / 디버깅 중 쌓인 "저장 글" 실패본 직접 정리(자동 삭제 금지).

## 초안 JSON 포맷 (`drafts/YYYYMMDD-slug.json`)

```json
{
  "title": "25~32자 제목",
  "tags": ["용산매운등갈비", "고봉당"],
  "place": { "query": "고봉당 용산", "name": "고봉당" },
  "video": { "path": "input/videos/a.mp4", "title": "40자 이내" },
  "blocks": [
    { "type": "text", "text": "문단\n줄바꿈은 \\n" },
    { "type": "subtitle", "text": "소제목" },
    { "type": "image", "path": "input/photos/3.webp", "caption": "선택" },
    { "type": "quote", "text": "핵심 문장" },
    { "type": "divider" }
  ]
}
```

- `place`: 지역 업종 글에서 필수. 지도는 글 맨 끝에 자동 삽입. 검색 0건이면 로그에 수동 첨부 필요로 표시.
- `video`: 선택. 있으면 항상 첫 text 블록 직후에 삽입(업로드 수 분 소요, 제목 필수·40자).
- `tags`: 5~10개, `#` 없이.
- `sponsored`: (선택, 에디터엔 안 들어감) 협찬이면 `true` — `naver_draft.js`가 첫 블록 표기 여부와 "내돈내산/광고 아님" 포함을 검사해 위반 시 중단. `--validate`로 브라우저 없이 초안만 검사 가능.
- 협찬이면 첫 블록은 표기 문구 text 블록.

## 사진·영상 처리

- 사진은 **분석한 스토리 순서**로 배치(파일 순서 아님).
- **모자이크(`scripts/mosaic.js`, 필수)**: 타인 얼굴·차량 번호판·전화번호 등 식별 정보 발견 시
  ① 영역 좌표(0~1 상대값, 상하좌우 15% 여유) spec을 `drafts/*.mosaic.json`에 저장
  ② `node scripts/mosaic.js drafts/xxx.mosaic.json` — 처리본은 `input/photos/_mosaic/`, 원본 덮어쓰기 없음
  ③ 처리본을 Read로 열어 실제로 가려졌는지 확인, 덜 가려졌으면 좌표를 키워 재실행
  ④ 초안엔 처리본 경로 사용
  좌표 기준은 **EXIF 회전 보정 후(보이는 화면 기준)**. 화자 본인 얼굴도 기본은 모자이크(공개 명시 시만 예외). 검수 보고에 처리 내역(몇 장·몇 영역·사유) 포함. sharp는 한 파이프라인에 resize 1회만 적용되므로 축소→버퍼→확대(nearest) 2단계로 분리(구현됨).
- **동영상**: `input/videos/`에 영상이 있으면 초안 `video` 필드에 넣는다.

## 자가 검증 원칙 (품질 엔진 — 가장 중요)

"했다"가 아니라 "됐는지 확인했다"로 끝낸다.
1. **이중 검증**: 임시저장 후 (a) 스크린샷 (b) 에디터 제목·본문 전체 텍스트 덤프(`drafts/*.dump.txt`)를 초안과 전문 대조. 스크린샷은 상단만 보이므로 **텍스트 덤프가 본검증**. 불일치하면 성공 보고 금지, 원인 수정.
2. 셀렉터 실패 시 추측으로 고치지 않는다 → `node scripts/probe_selectors.js`로 실제 DOM 실측 후 수정. 3회 실패하면 수동 붙여넣기용 원고 출력.
3. 문제 해결 시 아래 "교훈 로그"에 원인·해결책 기록, 안정 버전은 `scripts/naver_draft.working.js`로 백업. 다음 세션은 대화를 기억하지 못하므로 기억할 가치가 있는 건 전부 파일로.
4. 초안 검수 자가 질문: "모바일에서 인용구와 소제목만 훑어도 핵심이 전달되는가?"

## 실측 지식 (그대로 반영 — 추측으로 대체 금지)

- 본문 셀렉터는 `.se-section-text p.se-text-paragraph`로 한정. 제목도 내부적으로 같은 `p.se-text-paragraph` 구조라 범위를 넓히면 본문 클릭이 제목을 오염시킨다. 제목은 `.se-title-text`.
- **입력 순서: 본문 전체 먼저 → 제목은 맨 마지막.** 제목 입력 후 실제 값을 읽어 비교, 불일치면 전체선택·삭제 후 재입력. 본문 첫 줄도 저장 전에 앞 10여 자 포함 검사, 누락이면 맨 앞 보정 삽입.
- 뷰포트 **1600×1000 이상** (1400 이하면 패널이 열릴 때 속성 툴바가 잘림).
- 한글은 `keyboard.insertText()` (type()은 IME 꼬임). 이모지는 별도 호출로 분리 삽입(함께 넣으면 뒤 텍스트 유실).
- 인용구 버튼 `se-insert-quotation-default-toolbar-button`, 구분선 `se-insert-horizontal-line-default-toolbar-button`.
- **소제목은 볼드 토글 금지.** 문단 서식 드롭다운(`se-text-format-toolbar-button` → "소제목")을 쓴다. 기본 크기 30은 크므로 19(fs19)로 낮춘다. **순서: 서식 → 크기 → 텍스트 입력.** 입력 후 다음 문단은 "본문"으로 명시 복귀, 드롭다운 라벨을 다시 읽어 검증.
- text 블록이 연달아 오면 문단이 붙는다 → **다음 블록도 text일 때만** 끝에서 Enter 한 번 더.
- **태그**: 우상단 발행 버튼으로 패널 열기 → `input#tag-input`에 태그마다 입력+Enter(앞의 # 제거, 최대 30개) → Escape로 패널만 닫기 → 임시저장. 검증은 태그 영역 텍스트를 `#`로 쪼개 센다(칩 클래스는 해시가 바뀜).
- **지도**: 지도 툴바 → 장소 검색 → 결과 여러 개면 place.name과 공백 제거 정확 일치 → 부분 포함 → 첫 결과. "추가" 버튼은 hover 전 not visible → 항목 hover 후 클릭(폴백 DOM click). "추가" 전엔 확인 버튼 disabled. **팝업은 Escape로 안 닫힘 → 닫기 버튼 사용**, 안 닫으면 dim이 남아 이후 클릭이 전부 실패.
- **동영상**: 툴바 → 팝업 "동영상 추가"(`button.nvu_btn_append.nvu_local`)가 파일창을 띄움. 제목 필수(40자). 닫기 실패 시 DOM 강제 제거 폴백.
- 실행 로그 끝에 **"자동 처리 결과"** 블록(태그/지도/동영상/소제목)을 출력.
- `--dry-run`: 저장 클릭만 생략. 셀렉터 수정 중엔 항상 먼저 이걸로.
- 진입 시 "작성 중인 글" 팝업은 `.se-popup-button-cancel`(새로 쓰기)로 닫는다.
- 네이버 블로그 본문은 WebFetch 불가일 수 있다 → 재시도 말고 사용자에게 본문 붙여넣기 요청.
- 에디터는 `iframe#mainFrame` 안(프레임 없으면 페이지 자체가 에디터). 진입 URL `https://blog.naver.com/GoBlogWrite.naver`. 도움말 닫기 `.se-help-panel-close-button`. 사진 `button.se-image-toolbar-button`(파일선택창). 글자 크기 `se-font-size-code-toolbar-button`. 동영상 팝업 `.se-popup-video-upload`, 제목란 `.se-popup-video-upload input[placeholder*="제목"]`, 닫기 `button.nvu_btn_close`. 임시저장은 `button[class*="save_btn"]`, 폴백은 "저장" 텍스트 버튼.
- 셀렉터는 수시로 바뀐다. 실패 시 probe → 실측 → 수정. 3회 실패하면 수동 붙여넣기 원고.

## 사용자 안내

브라우저 자동화는 네이버 약관상 회색지대(본인 계정, 하루 1~2건 권장). `naver-profile/`는 로그인 세션이므로 외부 공유 금지(.gitignore 처리됨). 비밀번호는 저장하지 않는다 — 로그인은 사용자가 브라우저에서 직접 1회.

## 교훈 로그 (해결한 문제는 여기에 원인·해결 기록)

- (아직 실행 전 — 첫 `/write` 테스트 후 채울 것)
- **미검증 셀렉터(추정값, 첫 `--dry-run`에서 확인 후 이 목록 갱신)**: 이미지 캡션 `.se-caption`, 동영상 툴바 `button[class*="video"][class*="toolbar-button"]`, 동영상 확인 버튼 `.se-popup-button-confirm`, 지도 툴바 `button[class*="map"][class*="toolbar-button"]`·결과 항목 `li`+"추가", 발행 패널 열기 `button[class*="publish_btn"]`, 폰트크기 옵션 `[class*="fs19"]`/`[class*="fs15"]`, 인용구 탈출(ArrowDown). 위 "실측 지식"에 적힌 셀렉터만 검증된 값이다.
