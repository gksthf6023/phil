## 방문 기록

### 고봉당 (용산 · 매운등갈비)
- 업종: 매운등갈비 전문점으로 알려진 곳 (사용자 제공)
- 방문 목적: **내돈내산 (자비 방문)** — 협찬 아님 (사용자 확인, 2026-11-03)
- 방문: 토요일 오후 (예약 15:00, 14:40경 도착 → **웨이팅 없이 바로 입장**), 2명, 4인석에 편하게 앉음 (사용자 진술)
- 주차: 사용자 인상으로는 불가능해 보임 (직접 확인한 건 아님 → "확인은 못 했지만 어려워 보였다" 수준으로만)
- 교통: 용산역에서 도보 약 15분으로 기억 (불확실). 더 가까운 역이 있을 수 있음 → 확인 전엔 "용산역에서 걸었는데 15분쯤" 정도로만. 정확한 역·출구 미확인.
  - 참고(약한 출처, 구인공고): 주소 서울 용산구 한강대로54길 3 1층 → 사용자 확인 필요. 글에 확정 표기 금지
- 메뉴: 스크린샷(input/photos/_ref_menu_screenshot.png)에 "그시절, 80년대 치즈등갈비 19,000원" 표기. 단위(1인분/1판)·주문 수량 미확인. 스크린샷의 홍보 문구("연예인 방송인 환장" 등)는 글에 인용하지 않음.
- 우동사리: 주문했는지 서비스였는지 사용자 기억 불확실 → 가격·'서비스' 단정 금지. "함께 나왔다"로만.
- 김치 치즈 볶음밥: 가격 미확인
- 매운 정도: 사용자 체감 "불닭볶음면 정도" (본인 표현)
- 맛: 매우 만족 ("처음부터 끝까지 맛있었다")
- 단점: **양이 아쉬웠다**
- 모자이크: 불필요 (사용자 확인) — 4번 사진 일행 손·인형 그대로 사용
- 사진 4장: 1=김치치즈볶음밥, 2=우동사리+등갈비, 3=치즈등갈비 위에서, 4=치즈등갈비+리락쿠마 인형
- 미확인(글에서 뺌): 볶음밥·사리 가격, 정확한 역/출구, 영업시간·휴무, 좌석 외 분위기
