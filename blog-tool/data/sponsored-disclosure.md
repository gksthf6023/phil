# 협찬 표기 문구 (sponsored-disclosure.md)

공정위 「추천·보증 등에 관한 표시·광고 심사지침」 기준. **협찬·체험단 글은 글 상단 첫 블록에 일반 text 블록으로** 넣는다(quote 금지, 글 하단만 표기 금지).
업체가 지정한 문구가 있으면 그것이 우선.

## 대가 유형별 기본 문구
| 대가 유형 | 문구 |
|---|---|
| 무료 음식·서비스 제공 | 본 포스팅은 업체로부터 음식을 무료로 제공받아 작성한 후기입니다. |
| 원고료(금전) 수령 | 본 포스팅은 업체로부터 원고료를 지급받아 작성한 글입니다. |
| 음식 + 원고료 | 본 포스팅은 업체로부터 음식과 소정의 원고료를 제공받아 작성한 글입니다. |
| 할인·서비스 제공 | 본 포스팅은 업체로부터 할인(서비스)을 제공받아 작성한 후기입니다. |
| 체험단 플랫폼 경유 | 본 포스팅은 [플랫폼명]을 통해 업체로부터 [제공 내용]을 제공받아 작성한 후기입니다. |
| 제휴 링크 수수료 | 이 글의 링크를 통해 구매하면 일정 수수료를 제공받을 수 있습니다. |

## 금지 표현 (협찬 글)
- "내돈내산", "광고 아님", "협찬 없음", "자비로 구매" — 거짓 부인 표현은 위법.
- 협찬 표기를 사진·접힌 영역·해시태그로만 처리.

## 내돈내산 글
- 협찬 표기 불필요. 자비 방문이 **사용자 확인된 경우에만** "제 돈으로 다녀온" 표현 가능.
- 이후 협찬 제안을 받더라도 같은 글에 소급해 쓰지 않는다.
